# Laboratorio T3: manipulación y búsqueda de datos

Ejercicios introductorios de Python que muestran cómo manipular cadenas, relacionar datos con listas paralelas y consultar y ordenar registros de usuarios.

## Contenido

El programa [`main.py`](./main.py) ejecuta estos ejemplos:

1. Manipulación de cadenas: extraer una subcadena, buscar y reemplazar texto, y separar una frase en palabras.
2. Listas paralelas: buscar un nombre y mostrar la edad asociada.
3. Estructuras combinadas: almacenar usuarios como diccionarios y filtrar los que viven en una ciudad determinada.
4. Ordenamiento: mostrar alfabéticamente los nombres de los usuarios.

## Requisitos

- Python 3

## Ejecución

```bash
python main.py
```
